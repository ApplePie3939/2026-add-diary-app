# 仕様書

## プロジェクト概要

個人用の日記アプリ。日々の出来事・気分・思いを手軽に記録し、いつでも振り返れるようにする。
「最低限の操作で目標を達成できる」ことを重視し、Apple ライクで落ち着いたトーンの UI を提供する。

## 対象プラットフォーム

- iOS
- Android

## 技術スタック

| 分類           | 採用技術                                     |
| -------------- | -------------------------------------------- |
| フレームワーク | React Native (Expo SDK 54)                   |
| ルーティング   | expo-router v6                               |
| 言語           | TypeScript                                   |
| バックエンド   | Firebase (Firestore / Auth / Storage)        |
| 認証           | Firebase Authentication (メール＋パスワード) |
| データ永続化   | Cloud Firestore                              |
| 画像保存       | Firebase Storage                             |
| テスト         | Jest + jest-expo (ユニットテストのみ)        |
| CI/CD          | 未定（後日追加）                             |

## 画面一覧

### 1. 認証画面

- ログイン（メールアドレス＋パスワード）
- 新規登録
- パスワードリセット（任意・後日対応可）

### 2. 日記一覧（ホーム）画面

- ユーザーの日記を新しい順に一覧表示
- **無限スクロール**で追加読み込み（Firestore ページネーション）
- 各カードに表示する情報: アイコン（絵文字）・タイトル・日付・本文冒頭
- 画面上部に**検索バー**を配置し、タイトル・本文のキーワード検索が可能
  - 余裕があれば日付範囲フィルターも追加する
- 右下の FAB から日記作成画面へ遷移

### 3. 日記作成画面

- 以下のフィールドを入力できる

  | フィールド | 型                 | 必須 | 備考                                  |
  | ---------- | ------------------ | ---- | ------------------------------------- |
  | アイコン   | 絵文字（選択式）   | 必須 | プリセットから選ぶ                    |
  | タイトル   | テキスト           | 必須 |                                       |
  | 本文       | テキスト（複数行） | 必須 |                                       |
  | 日付       | 日付               | 必須 | デフォルトは当日                      |
  | 画像       | 画像ファイル       | 任意 | 端末から選択、Firebase Storage に保存 |

- 保存ボタンで Firestore に書き込み後、一覧画面へ戻る
- キャンセルで変更を破棄

### 4. 日記詳細画面

- 選択した日記の全内容を表示（アイコン・タイトル・日付・本文・画像）
- 編集画面へのリンク
- 削除ボタン（確認ダイアログあり）

### 5. 日記編集画面

- 作成画面と同じフォームを既存データで初期表示
- 保存で Firestore を更新し、詳細画面へ戻る
- キャンセルで変更を破棄

## データモデル

### Firestore コレクション構造

```
users/{userId}/entries/{entryId}
```

### Entry ドキュメント

| フィールド  | 型             | 説明                                |
| ----------- | -------------- | ----------------------------------- |
| `id`        | string         | ドキュメント ID                     |
| `userId`    | string         | 所有ユーザーの UID                  |
| `icon`      | string         | 絵文字（例: "☀️"）                  |
| `title`     | string         | タイトル                            |
| `body`      | string         | 本文                                |
| `date`      | Timestamp      | 日記の日付                          |
| `imageUrl`  | string \| null | Firebase Storage の画像 URL（任意） |
| `createdAt` | Timestamp      | 作成日時                            |
| `updatedAt` | Timestamp      | 更新日時                            |

## 機能仕様

### 無限スクロール

- 1 回あたりの取得件数: 20 件（変更可能な定数で管理）
- Firestore の `startAfter` カーソルを使ったページネーション
- リスト末尾に達したら次のページを自動取得

### 検索

- クライアントサイドでの部分一致フィルタリング（タイトル・本文）
- 一覧取得済みのデータに対して絞り込む（全件取得モードに切り替える必要あり）
- 将来的に日付範囲フィルターを追加予定

> **注意**: Firestore はネイティブの全文検索をサポートしないため、現フェーズではフロント側フィルタリングで対応する。データ量が増えた場合は Algolia 等の外部検索サービスへの移行を検討する。

### 画像アップロード

- `expo-image-picker` で端末のカメラロールから選択
- Firebase Storage へアップロード後、URL を Entry に保存
- 画像は `images/{userId}/{entryId}` に格納

### 認証・セキュリティ

- 未ログインユーザーは認証画面へリダイレクト
- Firestore Security Rules で `userId` を検証し、他ユーザーのデータへのアクセスを拒否

### オフライン対応

- 現フェーズはオンライン前提（ネットワーク未接続時はエラー表示）
- 将来的に Firestore のオフラインパーシステンス機能を有効化する予定

## UI / UX 方針

- **最低限の操作で目標を達成できる**設計
- Apple ライクな見た目（システムフォント、角丸、シャドウ、ホワイトカード）
- 落ち着いたトーン＋親しみやすさを両立するカラーパレット

### カラーパレット（既存コードより継承）

| 名称   | カラーコード | 用途                   |
| ------ | ------------ | ---------------------- |
| PAPER  | `#FAF6EE`    | 背景                   |
| INK    | `#2B2A28`    | テキスト               |
| SUB    | `#8A8278`    | サブテキスト           |
| ACCENT | `#8B5E3C`    | アクセント（ボタン等） |
| CARD   | `#FFFFFF`    | カード背景             |

## ディレクトリ構成（方針）

```
src/
  app/                  # expo-router のページコンポーネント
    (auth)/             # 認証画面グループ
      login.tsx
      register.tsx
    (app)/              # 認証後画面グループ
      _layout.tsx       # 認証ガード
      index.tsx         # 日記一覧（ホーム）
      new.tsx           # 日記作成
      [id]/
        index.tsx       # 日記詳細
        edit.tsx        # 日記編集
  components/           # 再利用コンポーネント
  hooks/                # カスタムフック
  lib/
    firebase.ts         # Firebase 初期化
  store/                # グローバル状態（Context）
  types/                # 型定義
```

## 開発方針

- **AI エージェント（OpenCode）を活用**して実装を進める
- コードは TypeScript で厳格に型付けする
- コンポーネントは小さく保ち、ロジックはカスタムフックに切り出す
- スタイルは `StyleSheet.create` で管理し、インラインスタイルは使わない
- テストはユニットテスト（`jest-expo`）のみ。store・hooks のロジックを中心にカバーする
- Firestore Security Rules は必ず設定し、データの安全性を担保する
